TrackPoint is a web application that allows someone to:
1. Track their own live location on a map.
2. Request another person's location.
3. Allow that person to accept or decline the request.
4. View the other person's live location once they accept.
5. Monitor movement, including speed, direction and distance travelled.
The central idea is that location tracking requires the tracked person to give permission.
It doesn't simply allow someone to enter another person's phone number and start tracking them
